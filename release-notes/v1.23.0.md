## Pindrop is discontinued

Pindrop 1.23.0 is the final release. Pindrop gets no new features, fixes, or support after it, and the repository is archived.

[Sayso](https://justsayso.app) replaces Pindrop. Sayso is a dictation app for macOS, Windows, and Linux from the same developer. On a Mac, Sayso can import your Pindrop dictations, dictionary, and prompt presets.

This version continues to work. Your transcripts, notes, and settings stay on your Mac. Pindrop shows a notice with this information on the first launch after the update.

## What's New

- **Three capture workflows**: Dictate writes speech into the app you are using. Voice Note turns a recording into a linked note and transcript. Meeting records the microphone and the system audio as separate sources.
- **Meeting notes**: long recordings are processed in recoverable chunks. Notes link to the final transcript, with speaker turns from live diarization.
- **Note page in the main window**: transcript, enhanced, and source views, per-view search, and an Ask conversation for each note.
- **Call detection**: Pindrop can offer to record when it detects a conference call.
- **OpenAI cloud transcription**: GPT-4o Transcribe and GPT-4o Mini Transcribe are available as optional models. API credentials stay in the macOS Keychain.

## Fixes and Improvements

- Fixed empty transcripts on Whisper models when the dictionary contains vocabulary words. WhisperKit is updated to 1.1.0. Dictations longer than 30 seconds do not use the vocabulary bias (#89).
- Fixed Apple Speech on-device transcription, which kept only the words after the last pause (#85).
- Fixed speaker diarization and voice activity detection downloads that finished and then reported "model files are incomplete" (#92).
- Fixed Parakeet v3 downloading to one folder and loading from another, which caused a load timeout. A complete model from 1.22.5 moves to the current folder, so you do not download it again (#86).
- Corrected the download sizes in the model list. For example, Whisper Large v3 Turbo is 3195 MB, not 809 MB, and Parakeet v3 is 470 MB, not 2670 MB (#103).
- Fixed the crash that closed Pindrop each time Quick Capture opened the note editor. Quick Capture is now part of Voice Note (#84).
- Replaced the malformed model load alert (#106).
- Repaired SwiftData stores that drifted from the expected schema.
